Agent 安全边界

监控 Agent 以低权限用户运行；需要停止进程、控制 systemd 或更新时，通过本机 Unix Socket 触发 systemd 按需启动的最小权限 Helper。Helper 不常驻、不开网络端口、没有 Shell 接口。
ALLOW: agent_ping agent_self_check system_info process_list process_info process_terminate process_kill process_restart process_start_saved service_stop service_restart disk_info network_info listening_ports sensor_info agent_upgrade DENY: shell / exec / script / bash / sh / custom_command TARGET RULE: service actions only for process-derived / explicitly approved units critical units and NodeLume itself are protected

域名

正式启用前需要先把域名解析到当前 Server。内置模式会先检查 80/443 是否冲突，再尝试申请证书；检查失败不会修改现有监听配置。
已有 Agent 时修改域名属于连接迁移。正式版会先验证新域名，再逐台下发受限的 endpoint migration，并要求旧域名保持可用直到所有节点迁移完成。
